# ربات معامله‌گر نوبیتکس — اتاق فرمان (نسخه وب و پیش‌نمایش موبایل)

این پروژه شامل داشبورد دوزبانه (فارسی/انگلیسی)، موتور تحلیل تکنیکال (TA)، موتور تحلیل فاندامنتال (FA)، موتور مدیریت ریسک، معاملات کاغذی (Paper Trading)، بک‌تست Walk-Forward، گرید سرچ و بک‌اند FastAPI است.

---

## 📱 مشاهده پیش‌نمایش روی گوشی موبایل (بدون نیاز به سرور یا نصب پایتون)

کدهای پروژه به‌گونه‌ای یکپارچه‌سازی شده‌اند که بدون نیاز به اجرای سرور پایتون، **۱۰۰٪ قابلیت‌های سیستم** (اسکنر نمادها، چارت کندل، تحلیل تکنیکال و فاندامنتال، میز معاملات دستی، کلید اضطراری، بک‌تست Walk-Forward و گرید سرچ) مستقیماً داخل مرورگر گوشی موبایل (Android و iOS) اجرا شوند:

1. **روش اول (تک‌فایل مستقل موبایل — پیشنهادی برای گوشی):**
   - فایل **`nobitex-mobile.html`** (یا **`index.html`**) را روی گوشی باز کنید (با Chrome، Safari، Samsung Internet یا حتی پیش‌نمایش داخلی تلگرام و فایل‌منیجر گوشی).
   - تمامی استایل‌ها، آیکون‌ها، چارت‌ها و موتورهای محاسباتی درون خود فایل قرار دارند و حتی در حالت **آفلاین** و تحت پروتکل‌های `file://` و `content://` اندروید و iOS بدون خطا کار می‌کنند.
2. **روش دوم (دانلود مستقیم از هدر داشبورد):**
   - در بالای داشبورد روی دکمه **«پکیج موبایل»** کلیک کنید تا فایل تک‌صفحه‌ای `nobitex-mobile.html` یا کل پکیج `nobitex-trader-robat.zip` را مستقیماً روی گوشی دانلود نمایید.
3. **نوار ناوبری پایین صفحه ویژه موبایل:**
   - در صفحه‌نمایش موبایل، یک نوار ناوبری لمسی در پایین صفحه برای جابه‌جایی سریع بین تب‌های اصلی («نمای کلی»، «سیگنال‌ها»، «فاندامنتال»، «میز دستی»، «ریسک» و «بک‌تست») فعال می‌شود.

---

## 💻 اجرا با بک‌اند پایتون (FastAPI) روی سرور یا دسکتاپ

```bash
cd server
python3 -m venv ../.venv
../.venv/bin/pip install -r requirements.txt
../.venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
```

سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.
