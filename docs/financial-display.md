# قرارداد نمایش مبلغ و بومی‌سازی

**فارسی** · [English](financial-display.en.md)

این تغییر صرفاً لایهٔ نمایش nobitrader است؛ `nbx-core.js`، سرور، مدل سفارش و نرخ‌های تبدیل تغییر نکرده‌اند.

## واحدها

| مقدار | واحد نمایش |
| --- | --- |
| سرمایه، تغییر مبلغ سرمایه و تخصیص حساب کاغذی | USD / دلار |
| قیمت، حد ضرر، اهداف، ارزش سفارش و عمق دفتر سفارش | ارز مظنهٔ همان بازار |
| مقدار خرید/فروش و مقدار پرشده | ارز پایهٔ بازار |
| سرمایهٔ ورودی، منحنی سرمایه و سود و زیان بک‌تست | ارز مظنهٔ بازار بک‌تست، نه USD حساب کاغذی |
| بازده، ریسک و افت سرمایه | درصد |

`IRT`/`TMN` یعنی تومان؛ `IRR`/`RLS` یعنی ریال؛ `USDT` تتر است، نه دلار حساب. هیچ تبدیل ارزی در formatter انجام نمی‌شود و تومان دوباره تقسیم بر ده نمی‌شود. واحد مظنهٔ ناشناخته حدس زده نمی‌شود. صفر معتبر نمایش داده می‌شود؛ مقدار خالی/نامعتبر/نامتناهی با `—` مشخص می‌شود.

## زبان، ارقام و ورودی

- متن و جهت صفحه از زبان انتخاب‌شده پیروی می‌کنند.
- `numFmt=auto` ارقام را با زبان هماهنگ می‌کند؛ انتخاب صریح `fa` یا `en` بر زبان مقدم است و با تعویض زبان پاک نمی‌شود.
- تاریخ از زبان/تقویم زبان پیروی می‌کند، اما دستگاه ارقام آن از همین تنظیم عدد پیروی می‌کند.
- مبلغ، علامت و واحد با Unicode bidi isolation از متن پیرامون جدا می‌شوند. مقدارهای جدول از هم نمی‌شکنند و جدول‌ها همچنان اسکرول افقی دارند.
- ورودی عددی به متن با صفحه‌کلید اعشاری تبدیل می‌شود، زیرا ورودی بومی `number` ارقام فارسی را نمی‌پذیرد. parser صریح ارقام فارسی، عربی و لاتین و جداکننده‌های متداول را به عدد واقعی تبدیل می‌کند؛ درخواست سفارش همچنان JSON با مقادیر عددی است.
- مکان نشانگر و composition حفظ می‌شود؛ محدودیت‌های min/max و step صریح در خروج از فیلد بررسی می‌شوند. این اعتبارسنجی جای دروازه‌های ریسک سرور را نمی‌گیرد.
- نمادهای ارز، نام محصول، شناسه‌ها، کلیدهای API، نسخه‌ها و جزئیات فنی خام ترجمه نمی‌شوند. داده‌ها و پیام‌های آزادِ دریافتی از سرویس‌ها مشمول ترجمهٔ خودکار نیستند.

## پیاده‌سازی و آزمون

formatter مشترک `window.NBXDisplay` در `index.html` و رندرکننده‌های `nbx-app.js` استفاده می‌شود. واحد صریح در هر renderer داده می‌شود؛ از متن یا ساختار DOM برای حدس واحد استفاده نشده است. گزارش بک‌تست و پاسخ حساب برای بازنمایی با زبان جدید نگه داشته می‌شوند، بدون اجرای مجدد معامله یا بک‌تست.

```sh
npm run build
npm run test:display
npm run test:js
python scripts/check_preflight_parity.py
npm run test:icons
npm run lint
npm run lint:dashboard
python -m pytest -q server/tests
ruff check server scripts
mypy
```

آزمون جدید هر دو فایل وب و مستقل را در ماتریس فارسی/انگلیسی × auto/fa/en بررسی می‌کند؛ شامل واحدها، صفر/مقدار خالی، bidi، ورودی/نشانگر/composition، بازنمایی فوری حساب هنگام تعویض زبان و برابری payload سفارش در دو زبان است. آزمون‌ها آفلاین و مبتنی بر jsdom هستند؛ ارزیابی چیدمان پیکسلی در مرورگر واقعی یا اتصال زندهٔ صرافی در این مرحله انجام نشده است. داده‌های fixture فقط در آزمون‌اند و به صفحه یا سرور افزوده نشده‌اند.
