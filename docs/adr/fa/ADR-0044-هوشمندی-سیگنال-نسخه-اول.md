# ADR-0044 — هوشمندی سیگنال نسخه اول

[English](../en/ADR-0044-signal-intelligence-v1.md) · **فارسی**

**وضعیت:** پذیرفته — در ۱٫۶٫۰ پیاده شد
**تاریخ:** ۲۰۲۶-۱۰-۲۵

## تصمیم

- تب «هوشمندی سیگنال» برای همه نقش‌های واردشده فقط‌خواندنی است و مستقیماً از `signal_log`، `signal_outcomes` و `gate_shadow` محاسبه می‌شود؛ داده یا نتیجه ساختگی ندارد.
- summary شامل resolved/unresolved/void کاملاً مجزا، win rate، expectancy، return، MFE/MAE و کف نمونه قابل مشاهده ۳۰ است. نتیجه R صفر صریحاً flat است و برد فرض نمی‌شود.
- شمارش مراحل judged، data-ready، gate-passed، signal generated و resolved همراه taxonomy واقعی gate code نمایش داده می‌شود. چون در v1 دفتر gate و signal شناسه چرخه مشترک ندارند، این اعداد نرخ تبدیل یک‌به‌یک معرفی نمی‌شوند.
- cohort بر اساس symbol/timeframe/regime/config hash محاسبه می‌شود تا نسخه‌ها و شرایط بازار مخلوط نشوند.
- جدول سیگنال‌ها نتیجه H1/H2/H3، MFE/MAE و review count دارد؛ detail، feature snapshot، امتیازهای ذخیره‌شده مؤلفه‌ها و همه outcomeها را نشان می‌دهد. امتیاز مؤلفه به‌اشتباه contribution علّی نامیده نمی‌شود.
- viewer می‌تواند تحلیل را بخواند؛ ثبت review/tag فقط operator/owner همراه CSRF است. capabilityهای اختصاصی `signal_intelligence_read` و `signal_intelligence_review` رفتار UI را تعیین می‌کنند. tagها allowlist ثابت دارند و audit `signal.review` ثبت می‌شود.
- review note حداکثر ۱۰۰۰ نویسه و همه داده‌های detail پیش از درج HTML escape می‌شوند.

## محدودیت نسخه اول

چرخه کامل execution-link، latency breakdown، calibration، drift و replay قطعی هنوز پیاده نشده‌اند. قیف gate و signal از دو ledger واقعی است و الزاماً conversion یک‌به‌یک ندارد؛ UI آن را به‌عنوان stage count نمایش می‌دهد، نه نرخ تبدیل ساختگی.
