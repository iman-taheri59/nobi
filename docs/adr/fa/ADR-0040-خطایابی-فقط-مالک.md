# ADR-0040 — تب خطایابی سیستم فقط برای مالک

[English](../en/ADR-0040-owner-only-troubleshooting.md) · **فارسی**

**وضعیت:** پذیرفته — در ۱٫۴٫۲ پیاده شد
**تاریخ:** ۲۰۲۶-۱۰-۲۵

## تصمیم

- تب «خطایابی سیستم» فقط پس از احراز session فعال مالک در navigation نمایش داده می‌شود.
- خواندن error log، catalogue تشخیص، نتایج devsuite و اجرای قبلی فقط session مالک را می‌پذیرد.
- اجرای diagnostics، پاک‌کردن log، self-test و اجرای devsuite علاوه بر owner به CSRF معتبر نیاز دارد.
- viewer/operator پاسخ 403 و کاربر ناشناس یا bearer API token پاسخ 401 می‌گیرد؛ دست‌کاری DOM کنترل backend را دور نمی‌زند.
- `POST /api/errors` برای گزارش خودکار خطای مرورگر تحت کنترل احراز عمومی باقی می‌ماند، اما مشاهده یا پاک‌سازی گزارش‌ها فقط مالک است.

## دلیل

error log می‌تواند مسیرها، وضعیت سرویس و context عملیاتی داشته باشد و diagnostics به شبکه و وضعیت داخلی دسترسی دارد. این اطلاعات و عملیات برای operator لازم نیست و کمینه‌سازی دسترسی بر سازگاری عقب‌رو اولویت دارد.
