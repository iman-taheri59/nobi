# ADR-0006: موتور تحلیل فاندامنتال — معماری و منابع داده

- **وضعیت:** پیشنهادی (Proposed)
- **تاریخ:** 2026-02-14
- **تصمیم‌گیرندگان:** معمار فنی، سرپرست پژوهش
- **ADRهای مرتبط:** 0002، 0007
- **کاتالوگ کامل متریک‌ها:** `docs/analysis/fundamental-analysis-capabilities.md`

---

## ۱. زمینه

تکنیکال به‌تنهایی نسبت به کیفیت توکن، تقویم آنلاک (آزادسازی)، سلامت آن-چین و شوک‌های خبری کور است. موتور FA یک `fa_score` کم‌سرعت (۰ تا ۱۰۰) برای هر دارایی تولید می‌کند به‌علاوه **وتوهای سخت** (پرچم‌های قرمز) که صرف‌نظر از تکنیکال، ورود را مسدود می‌کنند. همه ورودی‌ها در نسخه ۱ از APIهای رایگان/کم‌هزینه‌اند؛ دوره تازه‌سازی: ساعتی برای داده بازار، روزانه برای آن-چین، رویدادمحور برای اخبار.

## ۲. تصمیم — ارائه‌دهندگان داده و گروه‌های متریک

### ۲.۱ ساختار بازار و نقدشوندگی (ساعتی/روزانه)
| متریک | منبع |
|---|---|
| ارزش بازار، رتبه، FDV، عرضه در گردش/کل | API رایگان CoinGecko (جایگزین: CoinMarketCap) |
| نسبت حجم/ارزش‌بازار (فیلتر حجم جعلی) | CoinGecko + آمار داخلی نوبیتکس |
| دسترسی در صرافی‌ها و نقدشوندگی مخصوص نوبیتکس | ویژگی‌های عمق `/v3/orderbook` (ADR-0004) |
| عمر لیست شدن (ریسک لیست تازه) | تاریخ آغاز CoinGecko |

### ۲.۲ توکنومیکس و ریسک عرضه (هفتگی)
- نرخ تورم توکن، برنامه انتشار، **آنلاک‌ها/صخره‌های وستینگ** آتی (تقویم‌های تجمیعی مثل TokenUnlocks)
- تمرکز هولدرها (سهم ۱۰/۵۰ آدرس برتر در صورت دسترسی)، ذخایر تیم/داخلی
- دینامیک استیکینگ/بازده برای دارایی‌های PoS

### ۲.۳ سلامت آن-چین (روزانه) — نسخه ۱ فقط میجورها
سطوح رایگان: DefiLlama (TVL، کارمزدها، درآمد)، آمار RPC عمومی.
- رشد آدرس‌های فعال، تعداد تراکنش، روند کارمزد شبکه
- روند TVL و نسبت TVL/MCap (برای L1/L2 و توکن‌های DeFi)
- جریان استیبل‌کوین‌ها و خالص ورود/خروج صرافی‌ها (در صورت دسترسی)
- هش‌ریت/بودجه امنیت برای PoW (BTC، LTC، DOGE و...)
- نسبت NVT به‌عنوان کنترل صحت ارزش‌گذاری

### ۲.۴ NLP احساسات و اخبار (رویدادمحور + ساعتی)
| منبع | کاربرد |
|---|---|
| API اخبار CryptoPanic | جریان تیترها، رأی جامعه |
| فیدهای RSS رسانه‌های بزرگ کریپتو/اخبار | تشخیص رویداد |
| شاخص ترس و طمع (alternative.me) | اورلی رژیم کل بازار |
| متریک‌های اجتماعی (داده‌های CoinGecko؛ X API اگر بعداً مجوز گرفت) | سنجه هایپ/اسپم |
پایپ‌لاین تحلیل: دسته‌بندی احساسات چندزبانه (فارسی/انگلیسی) (واژه‌نامه + به‌صورت اختیاری LLM محلی)، اتصال موجودیت (BTC، ETH، نام‌های مستعار نمادها)، **طبقه‌بندی رویداد** (هک، دی‌لیست، مقررات، مشارکت، اکسپلویت، آنلاک) با وزن شدت. حذف تکرار + وزن‌دهی اعتبار منبع در برابر شیلینگ/دستکاری.

### ۲.۵ اورلی کلان (روزانه)
- DXY، اوراق آمریکا، طلا، دامیننس BTC؛ از فیدهای رایگان.
- **اورلی محلی ایران:** روند و نوسان پرمیوم بازار آزاد USDT/IRT (از خود نوبیتکس: بازار `USDTIRT`) — طبقه‌بند رژیم برای جهش تقاضای محلی و ریسک فروشدگی پرمیوم.

## ۳. مدل امتیازدهی
```
fa_score = w1·کیفیت‌بازار + w2·توکنومیکس + w3·سلامت‌آن‌چین + w4·احساسات + w5·تناسب‌کلان − جریمه‌ها
```
- وزن‌ها نسخه‌بندی‌شده در YAML؛ نرمال‌سازی هر متریک با z مستحکم/رتبه صدک (بریده‌شده).
- **قواعد وتوی سخت:** اعلان دی‌لیست صرافی، خبر هک/اکسپلویت حیاتی، آنلاک قریب‌الوقوع > X٪ ارزش‌بازار، فروپاشی عرضه اعلامی، توقف نوبیتکس، ارائه‌دهندگان داده کهنه.
- خروجی: `FARating { symbol, fa_score, vetoes: [...], evidence: {...مقادیر/لینک‌های قابل حسابرسی...} }`

## ۴. گزینه‌های بررسی‌شده
| گزینه | رأی |
|---|---|
| مجموعه‌های آن-چین پولی (Glassnode و...) در نسخه ۱ | رد (هزینه)؛ مسیر ارتقای اختیاری باز است |
| امتیازدهی خبری صرفاً LLM بدون نرده حفاظ | رد: ریسک توهم‌زایی؛ LLM اختیاری و پشت قواعد قطعی |
| کنارگذاشتن FA در نسخه ۱ | رد با توجه به الزام پروژه؛ اما به‌صورت ضریب + وتو تا TA لایه سرعت باقی بماند |

## ۵. پیامدها

**مثبت:** حذف دارایی‌های بیکیفیت و در معرض رویداد؛ بهره‌گیری از آلفای محلی (پرمیوم)؛ رد شواهد کاملاً قابل حسابرسی.

**منفی:** محدودیت نرخ/پایداری ارائه‌دهندگان (تسکین: کش، Circuit Breaker به‌ازای هر ارائه‌دهنده، پرچم کهنگی، تخریب تدریجی همان گروه متریک).
