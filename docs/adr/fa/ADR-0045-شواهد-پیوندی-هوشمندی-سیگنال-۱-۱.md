# ADR-0045 — شواهد پیوندی هوشمندی سیگنال ۱٫۱

**فارسی** · [English](../en/ADR-0045-signal-intelligence-v1-1.md)

**وضعیت:** پذیرفته و برای ۱٫۶٫۸ پیاده‌سازی شد  
**تاریخ:** ۲۰۲۶-۱۰-۲۵

## زمینه

داشبورد نسخهٔ اول داده‌های Scan، Gate و Outcome را از دفترهای مستقل کنار هم می‌گذاشت. نزدیکی زمانی ثابت نمی‌کرد که verdict و signal به یک تصمیم تعلق دارند. دادهٔ قدیمی باید بدون ساختن منشأ جعلی قابل استفاده بماند.

## تصمیم

۱. هر scan جدید یک `scan_cycle_id` مرتب‌پذیر زمانی و ۱۲۸ بیتی همراه هویت immutable موتور/پیکربندی می‌گیرد.
۲. جدول‌های `scan_cycles`، `scan_candidates` و `gate_verdict_reasons` چرخه، candidate، علت اصلی و همهٔ علت‌های normalized را نگه می‌دارند. کد ناشناخته حذف نمی‌شود و در گروه `unknown` می‌ماند.
۳. پیوند signal هنگام insert دفتر ثبت می‌شود. scan دوبارهٔ همان کندل بسته نمی‌تواند provenance چرخهٔ نخست را تصاحب کند. ردیف‌های قبلی `legacy-unlinked` هستند و inference بر پایهٔ timestamp ممنوع است.
۴. API پیوندی زیر `/api/v1/signal-intelligence` شامل summary، pipeline، علت‌های Gate، صفحه‌بندی پایدار `(ts,id)` و export محدود CSV/JSON است.
۵. Summary پوشش linkage، تفکیک pending-not-due از due-unresolved، Wilson 95% برای win rate و بازهٔ تقریبی نرمال 95% برای میانگین expectancy را گزارش می‌کند. کف نمونه صریح می‌ماند.
۶. سلول CSV که نخستین نویسهٔ قابل‌دیدنش پس از فاصله یا whitespace کنترلی یکی از `=`, `+`, `-`, `@` باشد با apostrophe خنثی می‌شود. export حداکثر ۱۰هزار ردیف و دارای audit است.
۷. Review انسانی append-only و فقط برای session اپراتور/مالک با CSRF است. read/export برای session احرازشده یا machine token پیکربندی‌شده مجاز است.

## سازگاری و قانون شکست

ساخت schema و افزودن ستون‌ها idempotent است. endpointهای v1 قدیمی حفظ می‌شوند. شکست ثبت evidence نباید scan بازار را متوقف کند و چرخهٔ ناقص `partial` می‌شود؛ scan بعدی چرخهٔ `running` رهاشده بر اثر crash را پس از یک ساعت recover می‌کند. شکست upstream به‌صورت candidate با وضعیت `scan-error` و شاهد `source-unavailable` حفظ می‌شود. counterfactual، contribution، هزینهٔ اجرا یا outcome حل‌نشده حدس زده نمی‌شود.

## پیامد

funnel برای چرخه‌های پس از migration واقعاً پیوندی است و coverage دورهٔ ترکیبی legacy را آشکار می‌کند. replay کامل، drift detection، attribution هزینهٔ اجرا و PostgreSQL خارج از دامنهٔ ۱٫۱ هستند.

## راستی‌آزمایی

migration/idempotency، پیوند قطعی، عدم سرقت provenance کندل تکراری، taxonomy چندعلتی، آمار و maturity، cursor، دفاع CSV، export دو قالب، API، نقش‌ها، Linux/Windows و UI gate انتشار هستند.
