# ADR-0043 — داشبورد «حساب من» برای همه نقش‌ها

[English](../en/ADR-0043-my-account-dashboard.md) · **فارسی**

**وضعیت:** پذیرفته — در ۱٫۵٫۱ پیاده شد
**تاریخ:** ۲۰۲۶-۱۰-۲۵

## تصمیم

- تب «حساب من» فقط برای session انسانی و برای viewer/operator/owner نمایش داده می‌شود؛ machine token داشبورد شخصی ندارد.
- `GET /api/auth/me` علاوه بر profile، capabilityهای محاسبه‌شده در backend، policy و مصرف live امروز و preferences را برمی‌گرداند. UI از role مجوز حدس نمی‌زند.
- کاربر فقط activity و sessionهای خودش را می‌بیند. endpoint فعالیت هیچ user_id ورودی نمی‌پذیرد؛ شناسه session دو بار hash و فقط به شکل public id ارائه می‌شود.
- بستن session، logout-all، تغییر preferences و تغییر password به CSRF نیاز دارند. بستن session فعلی یا تغییر password باعث reload/login مجدد می‌شود.
- preferences محدود و allowlisted هستند: زبان، timezone، theme و صفحه پیش‌فرض. نام کاربری و role فقط‌خواندنی‌اند.
- policy live اپراتور در حساب من فقط‌خواندنی است و مصرف روزانه/ظرفیت را نشان می‌دهد؛ تغییر policy فقط در تب owner Users باقی می‌ماند.

## امنیت و حریم خصوصی

هیچ token، session hash، password hash یا invite code به UI نمی‌رسد. User-Agent و IP فقط برای همان کاربر و session خودش نمایش داده می‌شوند. Owner همچنان مدیریت سراسری را از تب Users انجام می‌دهد و «حساب من» مسیر تغییر privilege نیست.
