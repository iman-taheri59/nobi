# ADR-0031 — روت‌های خصوصی کنترل، بدون روت ثبت واقعی

[English](../en/ADR-0031-private-control-routes.md) · **فارسی**

**وضعیت:** پذیرفته‌شده — B3-route در ۱٫۲٫۴ پیاده شد؛ place همچنان وجود ندارد
**تاریخ:** ۲۰۲۶-۱۰-۲۵
**مرتبط:** ADR-0018، ADR-0028، ADR-0029، ADR-0030

## زمینه

primitiveهای list/cancel/reconcile آماده‌اند، اما اپراتور نباید برای استفاده از آن‌ها کد پایتون اجرا کند. در عین حال عرضهٔ route ثبت پیش از اتصال preflight و audit خطرناک است.

## تصمیم و نیازمندی‌ها

1. router مستقل `/api/live` فقط status، list، cancel و reconcile عرضه می‌کند؛ **place ندارد**.
2. همهٔ روت‌های خصوصی با `require_client` محافظت می‌شوند؛ viewer و درخواست بدون CSRF/token رد می‌شوند.
3. حالت پیش‌فرض disabled است؛ live فقط با mode، عبارت تأیید و هر دو credential ساخته می‌شود.
4. sender همان raw body امضاشده را با `httpx` می‌فرستد و header/body را بازسازی نمی‌کند.
5. status هیچ secret، کلید عمومی، مسیر دیتابیس یا عبارت تأیید را نمایش نمی‌دهد.
6. خطای پیکربندی fail-closed است و سرور عمومی را از کار نمی‌اندازد.

## پذیرش

- OpenAPI هیچ `/api/live/place` نداشته باشد؛
- endpointهای کنترل بدون مجوز رد شوند؛
- حالت disabled پیش از شبکه خطا دهد؛
- status فقط mode، configured و placement_exposed=false را گزارش کند؛
- تست fixture مسیر list/cancel/reconcile را از router تا client اثبات کند.
