# ADR-0033 — دروازهٔ ارتقای اجرای واقعی از شواهد dry-run

[English](../en/ADR-0033-live-promotion-evidence.md) · **فارسی**

**وضعیت:** پذیرفته‌شده — B5 در ۱٫۲٫۶ پیاده شد؛ اعمال خودکار ندارد
**تاریخ:** ۲۰۲۶-۱۰-۲۵

## تصمیم

وجود signer و route برای فعال‌کردن live کافی نیست. ledger باید حداقل ۳۰ intent آزمایشی روی حداقل ۵ روز متمایز داشته باشد، هیچ وضعیت `unknown`/`cancel-unknown` نداشته باشد و همهٔ نمونه‌ها به نتیجهٔ قابل توضیح رسیده باشند. API فقط شاهد و دلیل عدم آمادگی را گزارش می‌کند؛ هرگز mode را خودکار تغییر نمی‌دهد.

## پذیرش

- شمارش بر اساس ردیف یکتا، نه polling؛
- روز از `created_at` پایدار ledger؛
- unknown حتی با نمونه کافی ready را false کند؛
- دیتابیس خالی عدد ساختگی نسازد؛
- `/api/live/evidence` خصوصی و بدون secret/path باشد؛
- هیچ live placement افزوده نشود.
