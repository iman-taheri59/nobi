# ADR-0048 — نصبگر قابل ادامهٔ سرور از مرورگر و helper محدود سیستم‌عامل

**فارسی** · [English](../en/ADR-0048-resumable-browser-server-installer.md)

**وضعیت:** پذیرفته و برای ۱٫۹٫۰ پیاده‌سازی شد
**تاریخ:** ۲۰۲۶-۱۰-۲۵
**مرتبط:** ADR-0035 و ADR-0036

## زمینه

ساخت Owner، تنظیمات غیرمحرمانه و gateهای پروژه از مرورگر موجود بود، اما نصب systemd/nginx و restart هنوز shell می‌خواست. root کردن فرایند وب یا پذیرش متن فرمان، برنامه را به remote shell تبدیل می‌کرد.

## تصمیم

ویزارد فقط-Owner هشت مرحلهٔ قابل ادامه را در SQLite ذخیره می‌کند: bootstrap-owner، host-preflight، storage، runtime، reverse-proxy، service-install، validation و complete. mutationها session و CSRF می‌خواهند و lock سراسری دارند. preflight بدون تغییر میزبان، سیستم‌عامل، non-root بودن، Python، دیسک، writable بودن داده، پورت‌ها، helper، systemd و nginx را گزارش می‌کند.

عملیات privileged فقط از یک مرز protocol-versioned **روی سوکت یونیکس** عبور میکند. فرایند وب فقط یک action ID مجاز را به `nobi-helper-client` میدهد؛ کلاینت به `/run/nobi-installer.sock` (گروه nobi، mode 0660) وصل میشود و سرویس root متصل به همان سوکت، action را اعتبارسنجی و CLI helper را اجرا میکند. هیچ sudo، باینری setuid یا قانون sudoersای در کار نیست: `NoNewPrivileges=yes` و `ProtectSystem=strict` یونیت وب، sudo را بیکار میکنند و سرویس helper namespace مخصوص خودش را دارد. قالبها root-owned و بیرون از checkout (که کاربر سرویس مالک آن است) در `/usr/local/share/nobi-installer` نگهداری میشوند و مالک، mode و محتوایشان پیش از نصب بررسی میشود. دامنه از فایل root-owned `/etc/nobi/domain` میآید، نه از درخواست مرورگر. فایلها مسیر ثابت، backup، جایگزینی atomic، اعتبارسنجی nginx و timeout محدود دارند.

خروجی محدود و از الگوهای secret پاک‌سازی می‌شود. restart، reload و rollback تأیید صریح می‌خواهند. Live فقط disabled/dry-run می‌ماند و این ویزارد آن را promote نمی‌کند.

## شکست و rollback

هر action یک run immutable می‌سازد و وضعیت مرحله را running، passed یا failed می‌کند. فایل‌های قبلی service/proxy پیش از جایگزینی backup می‌شوند. rollback فقط targetهای ثابت را بازمی‌گرداند و systemd/nginx را دوباره اعتبارسنجی می‌کند. refresh مرورگر وضعیت ذخیره‌شده و runهای اخیر را می‌خواند.

## ناورداهای امنیتی

- فرایند وب هرگز root نیست؛
- session مالک و CSRF الزامی است؛
- action و argv helper allowlist بسته دارند؛
- shell، قانون sudo، قالب قابلنوشتن توسط سرویس، path کاربر و package دلخواه ممنوع است؛
- secret در تنظیمات managed، state، log، خروجی API یا audit ذخیره نمی‌شود؛
- mutation هم‌زمان fail-closed است؛
- Paper Trading پیش‌فرض استقرار باقی می‌ماند.
