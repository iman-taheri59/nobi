# ADR-0058: یک منبع HTML ریسپانسیو؛ حذف خروجی مستقل

[English](../en/ADR-0058-one-responsive-html-source.md) · **فارسی**

- **وضعیت:** پذیرفته و در شاخهٔ کاری پیاده‌سازی شده؛ هنوز منتشر یا مستقر نشده
- **تاریخ:** ۲۰۲۶-۱۱-۰۳
- **صاحب تصمیم:** کارفرما؛ انتخاب صریح «حذف کامل» پس از روشن‌سازی دامنه
- **مرتبط:** ADR-0019 (تصمیم پیشین، اکنون superseded)، ADR-0016 (CI)
- **پیاده‌سازی/شاهد:** `index.html`، `server/main.py`، `server/tests/test_single_page.py`، آزمون‌های responsive در `scripts/`، workflowهای CI و Release

---

## تصمیم

`index.html` تنها منبع HTML داشبورد و همان صفحهٔ ریسپانسیو برای گوشی و دسکتاپ است. مسیرهای `/` و `/index.html` دقیقاً همین فایل را سرو می‌کنند.

خروجی تولیدی `nobitex-mobile.html` و سازندهٔ `scripts/build_standalone.py` حذف می‌شوند. route فایل، انتخاب صفحهٔ مستقل در `/`، ساخت خودکار/تشخیص کهنگی مربوط به آن، گیت تازه‌بودن آن در CI و پیوست موبایل در GitHub Release نیز وجود نخواهند داشت. `npm run build` همچنان آیکون‌های محلی و CSS کامپایل‌شده را می‌سازد؛ کامپایل و گیت تازه‌بودن CSS بخشی از خروجی مستقل HTML نیستند و باقی می‌مانند.

## پیامدهای تست و استقرار

- آزمون‌های parity که دو HTML را مقایسه می‌کردند حذف می‌شوند. تست‌های واقعی responsive در viewportهای موبایل و دسکتاپ روی `index.html` حفظ می‌شوند.
- تست‌های wiring و DOM که قبلاً HTML تولیدی را ورودی می‌گرفتند، به منبع canonical منتقل می‌شوند.
- CSS و JavaScript محلی همچنان از routeهای دارایی سرو می‌شوند؛ صفحهٔ `/` در زمان پاسخ درخواست build یا فایل دیگری انتخاب نمی‌کند.
- workflow انتشار فقط یادداشت Release را منتشر می‌کند و فایل HTML موبایل پیوست نمی‌کند. آرشیو منبع GitHub تغییر مستقلی از این پیوست است.
- این تصمیم مجوز deploy یا انتشار نیست؛ تأییدهای عملیاتی لازم جداگانه‌اند.

## محدودهٔ تغییر

این تصمیم فقط به منبع/بسته‌بندی صفحه، routeها، CI/Release، تست‌ها و مستندات مربوط است. منطق معامله، رفتار سفارش و WebSocket عمداً خارج از دامنه‌اند و نباید در همین تغییر دست‌کاری شوند.

## دلیل

فایل HTML دوم یک نسخهٔ دستی نیست، اما همچنان دادهٔ تولیدیِ tracked با سازنده، route، pipeline انتشار و تعداد زیادی parity test است. همان مسئولیت را می‌توان با یک صفحهٔ canonical ریسپانسیو و assetهای محلی انجام داد؛ نگه‌داشتن فایل دوم ارزش عملیاتی کافی ندارد و خطر جا ماندن یا سردرگمی بین دو پاسخ را ایجاد می‌کند.

ADR-0019 در زمان خودش دلیل نگه‌داشتن یک خروجی درون‌خطی از همان صفحه را ثبت می‌کند. این ADR تصمیم را عوض می‌کند: یک منبع HTML باقی می‌ماند، ولی خروجی مستقل حذف می‌شود.
