# ADR-0036 — مرکز عملیات مالک با allowlist ثابت

[English](../en/ADR-0036-owner-operations-center.md) · **فارسی**

**وضعیت:** پذیرفته‌شده — W3 در ۱٫۳٫۲ پیاده شد؛ W3b helper سیستم‌عامل در انتظار
**تاریخ:** ۲۰۲۶-۱۰-۲۵
**مرتبط:** ADR-0016، ADR-0017، ADR-0035

## زمینه

داشبورد قبلاً فقط pytest، ruff و mypy را با دسترسی operator اجرا می‌کرد. درخواست محصول این است که تمام تست‌ها، build و بررسی استقرار بدون خط فرمان و فقط توسط owner قابل اجرا باشند. پذیرش command یا آرگومان دلخواه، وب‌اپ را به remote shell تبدیل می‌کند.

## تصمیم

- سه endpoint موجود devsuite فقط با session نقش owner قابل دسترسی‌اند؛ API token و operator کافی نیست.
- عملیات از tuple ثابت `Gate` می‌آیند و فقط runnerهای `python` و `npm` دارند؛ `shell=True` و متن command ورودی وجود ندارد.
- allowlist شامل pytest، ruff، mypy، ESLint، lint صفحه، تست بروکر، intrabar، display، adaptive card، icons، preflight parity، build و deploy-check است.
- در هر لحظه فقط یک run، timeout کلی هر gate، خروجی tail محدود و storage تست ایزوله است.
- build و deploy-check ممکن است fail شوند و خروجی واقعی‌شان نمایش داده می‌شود؛ UI نتیجه نمی‌سازد.

## پذیرش

- operator/viewer و درخواست بی‌نشست رد شوند؛
- نام ناشناخته 400 و command دلخواه غیرقابل بیان باشد؛
- هیچ gate شامل shell metacharacter نباشد؛
- تمام فرمان‌های CI/ساخت مستندشده در allowlist باشند؛
- خروجی و وضعیت از همان runner فعلی در UI دیده شوند.

## باقی‌مانده

restart/install system package و restore مخرب نیازمند helper جدا، non-root و policy سیستم‌عامل است و در W3b خواهد آمد؛ داخل process وب اجرا نمی‌شود.
